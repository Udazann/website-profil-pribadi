WEBSITE PROFIL PRIBADI — PETUNJUK PEMULA

ISI FOLDER
- index.html : struktur dan isi website.
- style.css  : warna, layout, font, dan tampilan responsif.
- script.js  : menu HP dan tahun otomatis di footer.
- assets/foto-profil.svg : gambar ilustrasi sementara.

CARA MEMBUKA DI VS CODE
1. Ekstrak file ZIP ini.
2. Buka VS Code.
3. Pilih File > Open Folder, lalu pilih folder website-profil-pribadi.
4. Buka index.html. Untuk melihat website, klik kanan index.html lalu pilih
   "Open with Live Server" jika ekstensi Live Server sudah terpasang.
   Kalau belum ada, buka file index.html langsung dari File Explorer.

BAGIAN YANG WAJIB KAMU GANTI
1. Cari "Nama Kamu" di index.html, lalu ganti dengan nama lengkapmu.
2. Ganti "Kota Kamu", "Nama Universitas", "Nama Program Studi", dan nama sekolah.
3. Ubah deskripsi diri dan [tulis hobi kamu] agar sesuai dengan dirimu.
4. Isi pendidikan, organisasi, kepanitiaan, prestasi, dan proyek yang benar-benar kamu miliki.
5. Ganti email, Instagram, dan GitHub dengan akun milikmu.
6. Ganti assets/foto-profil.svg dengan foto pribadi. Cara termudah:
   - Masukkan foto ke folder assets dan beri nama foto-profil.jpg.
   - Buka index.html, cari src="assets/foto-profil.svg"
   - Ganti menjadi src="assets/foto-profil.jpg"

CATATAN
- Jangan mengaku punya pengalaman atau prestasi yang tidak benar. Jika belum punya,
  tulis bahwa kamu sedang belajar atau gunakan proyek latihan.
- CSS sudah memiliki aturan responsif untuk HP dan laptop.
- Sebelum dikumpulkan, uji semua tautan dan cek tampilan pada ukuran layar berbeda.
- Untuk tugas deployment, ikuti petunjuk dosen: push file ke repository GitHub,
  lalu import repository itu ke Vercel.
